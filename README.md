# Kai Prevention Mobile App

Este é o aplicativo móvel do Kai Prevention, uma plataforma para gerenciamento de prevenção médica.

## Requisitos

- Node.js 14+
- npm ou yarn
- Expo CLI

## Instalação

1. Clone o repositório:
```
git clone <repository_url>
cd kai-mobile
```

2. Instale as dependências:
```
npm install
```

3. Execute o projeto:
```
npm start
```

## Estrutura do Projeto

- `src/components`: Componentes reutilizáveis
- `src/screens`: Telas da aplicação
- `src/navigation`: Configuração de navegação
- `assets`: Imagens e outros recursos

## Telas Implementadas

- Login: Tela de login para acessar a conta
- Registro: Tela para criar uma nova conta
- Home: Tela inicial depois do login (placeholder)
